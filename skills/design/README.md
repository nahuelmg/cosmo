# Design Skills

This directory references the **ui-ux-pro-max** skill for all design decisions.

## How Design Fits In

1. **General SKILL.md** handles engineering methodology (architecture, patterns, data flow)
2. **Domain skills** handle domain-specific technical patterns
3. **ui-ux-pro-max** handles all visual/UX design decisions:
   - Color palette selection and design tokens
   - Typography and spacing systems
   - Component visual design
   - Layout and composition
   - Responsive breakpoints
   - Animation and interaction design
   - Accessibility from a design perspective

## When to Consult

- Starting a new project's visual design
- Choosing between layout approaches
- Evaluating color schemes and contrast
- Making responsive design decisions
- Polishing UI after core features are built

## Integration

The general SKILL.md's "Design Token Management" section covers the *technical* implementation of design tokens (CSS variables, Tailwind theme, canvas color workarounds). For *which* tokens to choose and *why*, defer to ui-ux-pro-max.
