# Web Dev Framework

Template repository for starting new web development projects with Claude Code.

## What's Included

```
├── CLAUDE.md              ← Claude reads this first (loads skills, sets conventions)
├── GUIDE.md               ← Step-by-step: project from zero to deployed
├── skills/
│   ├── web-dev-general/   ← General methodology (always applies)
│   ├── domains/           ← Domain-specific skills (dashboard, landing page, etc.)
│   └── design/            ← References ui-ux-pro-max
└── .planning/             ← GSD workflow scaffold
```

## Usage

1. Click **"Use this template"** to create a new repo for your project
2. Clone locally and open with Claude Code
3. Follow `GUIDE.md`
