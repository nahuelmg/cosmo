# Cosmo — plain HTML website

The user explicitly chose to replace the Next.js authoring system with directly editable plain HTML, CSS and vanilla browser JavaScript. Python performs marked-region updates and content synchronization. Do not reintroduce React, Next.js, TypeScript, Tailwind or Node package/build dependencies.

## Current architecture

Read README.md and GUIDE.md. Committed root HTML, `es/`, `en/`, `assets/` and root image directories are the website source. Edit HTML directly. Do not reintroduce full-page generation. Only marked AUTO regions are generated by `tools/update_html.py` and `tools/render.py`; templates under `tools/templates/` are fragments and new-profile scaffolds. Keep manual markup outside markers unchanged. Preserve retired profiles through `content/profile-history.json`.

`tools/build.py` packages website files only into ignored `dist/`. `tools/sync.py` retains existing data sources and enrichment. Local update transactions stage and validate data/HTML before applying changes. `tools/ci_sync.py` commits validated changes in disposable worktrees and retries from fresh main on concurrent pushes; never force-push.

## GitHub Pages

Preserve https://nahuelmg.github.io/cosmo/ and the `/cosmo/` prefix. URLs are committed HTML; site configuration and build-info must agree. Preview the repository directly with `python -m tools.preview`. Check both languages, direct links, refresh, redirects, assets and profile language switching.

Pages deploys validated `dist/` after main pushes and successful completion of **Sync content and generate HTML**. Keep the workflow_run trigger because bot commits do not trigger push workflows. PRs never deploy. Sync schedules remain 00:00 publications, 00:15 journal club and 00:30 people UTC. Research remains manual.

## Checks

```bash
python -m tools.content
python -m unittest discover -s tests -v
python -m tools.build
python -m tools.check dist
python tests/browser_check.py
```

Install `requirements.txt` for automation and unit tests; `requirements-dev.txt` adds browser testing. Browser tests use installed Chrome by default or Playwright Chromium with `CHROME_PATH=chromium`.

Committed HTML is the permanent source. Do not commit `dist/`, ZIP artifacts, screenshots or local environments.
