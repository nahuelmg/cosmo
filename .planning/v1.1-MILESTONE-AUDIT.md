## E2E Flows

**Maintainer workflow (the milestone's core promise):**
1. Maintainer adds `inspirehep_id` and/or `orcid_id` to `content/people.json`
2. Weekly cron (Monday 06:00 UTC) or manual workflow_dispatch fires
3. Sync script fetches InspireHEP + arXiv, merges manual overrides
4. Writes `content/publications.json` with `_meta.synced_at`
5. jq payload diff vs HEAD — if publication list changed, commit + push
6. Vercel redeploys on push → 45 static routes rebuild
7. `/publications` shows updated list with source filter, staleness line, member-author highlighting
8. `/people/[slug]` shows that member's last-10-years publications

**Status: connected end-to-end, verified by code inspection + live build.**
