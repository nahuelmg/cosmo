- **JsonLd placement:** Render `<JsonLd>` INSIDE the `<body>`, as a sibling of `<main>`/`<SiteFooter>`. Next.js hoists `<script type="application/ld+json">` appropriately. Do NOT render it inside `<head>` manually.
- **Locale typing:** the existing `Locale = (typeof routing.locales)[number]` stays; cast the awaited `locale` string to `Locale` when calling `buildOrganizationSchema(locale)` — after `hasLocale(...)` guard this cast is safe.
</constraints>

    3. Add a static `metadata` export above `generateStaticParams`:
       ```ts
       export const metadata: Metadata = {
         metadataBase: new URL(siteConfig.url),
         title: {
           default: siteConfig.groupName,
           template: `${siteConfig.groupName} — %s`,
         },
         description: siteConfig.tagline.es,
         openGraph: {
           siteName: siteConfig.groupName,
           type: "website",
           images: [{ url: "/Portadas/portada_1.jpg", width: 1920, height: 820 }],
         },
         twitter: {
           card: "summary_large_image",
           images: ["/Portadas/portada_1.jpg"],
         },
       };
       ```
       Notes:
       - `metadataBase` lets child `openGraph.images: ["/Portadas/portada_1.jpg"]` resolve to absolute URLs automatically (Pitfall 4 in RESEARCH.md).
       - `title.default` is used only when no child sets a title — the template is applied to children that DO set a title (e.g. 05-03's pages).
       - `description: siteConfig.tagline.es` is a last-resort fallback; every page overrides it via generateMetadata.

       return (

             </NextIntlClientProvider>
