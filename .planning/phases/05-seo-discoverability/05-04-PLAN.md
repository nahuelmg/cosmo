<constraints>
- **NAV-03 (critical):** The Person schema builder in 05-01 omits `email`. Do NOT add it here under any circumstance. ORCID → `identifier`, Scholar → `sameAs`, and social_links URLs → `sameAs` are the discovery vectors.
- **PERF-01 (critical):** generateStaticParams on this route is already generating all clickable slugs (PI + Postdoc + PhD × 2 locales = 13 × 2 = 26 params). After this change the route MUST still appear in the build output as a static bucket — look for the `/people/[slug]` entry with concrete generated paths and the `○` marker. Any fallback to dynamic is a blocker.
- **Shared OG image (CONTEXT.md 2026-04-18 update):** Do NOT use `person.photo` as the OG image. The shared `/Portadas/portada_1.jpg` is used for every page, including person detail pages, because member portraits are roughly square and compose poorly at 1200×630 on social platforms. `buildPageMetadata`'s default `ogImage` already handles this; simply don't override it.
- **notFound behavior:** The existing page already calls `notFound()` for unknown slugs. `generateMetadata` must follow the SAME guard — return `{}` if `getPersonBySlug(slug)` returns undefined, to avoid producing metadata for a 404 page.
- **href key:** Pass `/people/[slug]` as the href literal (e.g. `\`/people/${slug}\``). next-intl's pathnames config handles the localization to `/personas/${slug}` for Spanish.
- **Title:** Use `person.name` (canonical, per schema — not bilingual). Description is localized role + siteConfig.groupName (e.g. "Investigador Principal — Grupo de Cosmología"). Use `localize(person.role, locale)`.
</constraints>

       }: {
         params: Promise<{ locale: string; slug: string }>;
       }): Promise<Metadata> {
         const { locale, slug } = await params;
         const person = getPersonBySlug(slug); // or existing accessor name
         if (!person) return {};

         const localizedRole = localize(person.role, locale as Locale);
         const description = `${localizedRole} — ${siteConfig.groupName}`;

         return buildPageMetadata({
           locale,
           href: `/people/${slug}`,
           title: person.name,      // canonical, not bilingual (per schema)
           description,
           ogType: "profile",
           // ogImage omitted → buildPageMetadata falls back to /Portadas/portada_1.jpg
           // per CONTEXT.md 2026-04-18 update: no per-page portrait OG
           absoluteTitle: false,    // template suffix "— Grupo de Cosmología" is desired
         });
       }
