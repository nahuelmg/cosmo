<task type="auto">
  <name>Task 3: Create SkipLink and wrap layout children in <main>#main-content</main></name>
  <files>src/components/layout/SkipLink.tsx, src/app/[locale]/layout.tsx</files>
  <action>
Create `src/components/layout/SkipLink.tsx` as a pure server component (no `'use client'`). It renders a visually-hidden anchor that becomes visible on keyboard focus and jumps to `#main-content`. Use next-intl's server-side `getTranslations({ locale, namespace: 'layout' })` so the label swaps between Spanish and English:

```tsx
import { getTranslations } from 'next-intl/server';

interface SkipLinkProps {
  locale: string;
}

export async function SkipLink({ locale }: SkipLinkProps) {
  const t = await getTranslations({ locale, namespace: 'layout' });
  return (
    <a
      href="#main-content"
      className={[
        'sr-only focus:not-sr-only',
        'focus:fixed focus:top-4 focus:left-4 focus:z-[100]',
        'focus:bg-surface focus:text-ink',
        'focus:px-4 focus:py-2 focus:rounded',
        'focus:shadow-md focus:outline-none',
        'focus:ring-2 focus:ring-accent-ring',
        'font-sans text-sm font-semibold',
      ].join(' ')}
    >
      {t('skipToContent')}
    </a>
  );
}
```

Styling rationale (respects the 01-02 no-border / typography-first / shadow-ceiling rules): sr-only by default, teleports to fixed top-left on focus, uses `--shadow-md` (within ceiling) for separation, uses `focus:ring-2 focus:ring-accent-ring` as the focus indicator via box-shadow (existing token, no border violation), and `focus:z-[100]` to sit above every other Phase 3 surface (header z-30, mobile overlay z-40, drawer z-50 per RESEARCH.md z-index ladder).

Then edit `src/app/[locale]/layout.tsx`. The current body is:

```tsx
<body className="bg-surface text-ink antialiased">
  <NextIntlClientProvider>{children}</NextIntlClientProvider>
</body>
```

Restructure it to (inside the existing `<NextIntlClientProvider>` so `useTranslations` works in descendants):

```tsx
<body className="bg-surface text-ink antialiased">
  <NextIntlClientProvider>
    <SkipLink locale={locale} />
    <main id="main-content" tabIndex={-1}>
      {children}
    </main>
  </NextIntlClientProvider>
</body>
```

Import at the top of the file: `import {SkipLink} from '@/components/layout/SkipLink';`

Critical details:
- `tabIndex={-1}` on `<main>` is NOT optional — without it, activating the skip link scrolls but keyboard focus stays at the link (RESEARCH.md Pitfall #3, fails WCAG 2.4.1).
- `SkipLink` must be the FIRST child of `<body>` inside the provider so it is the first focusable element in tab order.
- Do NOT add `overflow` or `flex` layout classes to `<main>` in this task — Header/Footer plans handle layout. Only `id` and `tabIndex` go on `<main>` right now.
- Do not modify the `hasLocale` / `setRequestLocale` sequence — that ordering is locked (STATE.md 01-04 decision).
- Do not delete or modify the existing HomePage's inner `<main>` element in `src/app/[locale]/page.tsx` — that's Phase 4's concern; two nested `<main>` elements will produce an a11y warning but won't break the build. The Header plan will eventually replace HomePage's inner wrapper; for now, leave HomePage alone so this plan stays scoped.
