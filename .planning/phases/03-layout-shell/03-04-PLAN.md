<objective>
Assemble the sticky top header — the chrome every page will wear. Desktop layout: logo on the left, 7 nav links centre-right, LocaleToggle on the far right. Mobile layout (below `md` breakpoint): logo + hamburger button, tap to open a Radix Dialog drawer containing the same 7 nav links stacked vertically plus the LocaleToggle pinned at the bottom. The drawer closes on tap-a-link, Escape, or the close button, with focus trapped inside while open and returned to the trigger when closed.

Purpose: This plan delivers Success Criteria 1 (7-link nav with active indicator), 4 (responsive collapse + no horizontal overflow), and part of 2/6 (locale toggle placement, translated labels). Using Radix Dialog for the mobile drawer is not negotiable — RESEARCH.md confirms hand-rolling a focus trap is the single most common source of mobile-a11y regressions, and Radix handles all edge cases (iOS Safari, aria-modal, return-focus, body scroll lock) correctly. This plan does NOT wire the header into `layout.tsx` — that's Plan 05's job, alongside the footer integration, so Plan 05 can do the one-shot `view-source` verification after the complete shell exists.

Output:
- `src/components/layout/SiteHeader.tsx` — `'use client'` boundary (because it embeds NavLink which is client). Sticky, 56px tall, warm surface, `shadow-sm` separator, max-width container aligned with site's existing content width. Renders `<Image src="/logo_cosmo.png">` inside a `<Link href="/">` on the left; desktop nav + LocaleToggle on `md:flex`; `<MobileNav />` visible only below `md`.
- `src/components/layout/MobileNav.tsx` — `'use client'`. Radix Dialog: trigger is a hamburger button; drawer slides in from the right (`inset-y-0 right-0 w-72`), contains the 7 NavLinks stacked with large tap targets, and pins `<LocaleToggle>` + close-button controls. `onNavigate` per NavLink calls `setOpen(false)`.
</objective>

  <name>Task 1: Build MobileNav — Radix Dialog drawer with focus trap</name>
  <files>src/components/layout/MobileNav.tsx</files>
  <action>
Create `src/components/layout/MobileNav.tsx` as a `'use client'` component that owns the drawer state and uses Radix Dialog for accessibility-correct modal behaviour. The component accepts no props — it reads `NAV_ITEMS` internally and composes `NavLink` + `LocaleToggle`.

```tsx
'use client';

import {useState, useEffect} from 'react';
import * as Dialog from '@radix-ui/react-dialog';
import {useTranslations} from 'next-intl';
import {usePathname} from '@/i18n/navigation';
import {NAV_ITEMS} from './nav-items';
import {NavLink} from './NavLink';
import {LocaleToggle} from './LocaleToggle';

export function MobileNav() {
  const [open, setOpen] = useState(false);
  const t = useTranslations('layout');
  const tNav = useTranslations('nav');
  const pathname = usePathname();

  // Auto-close when route actually changes (belt-and-braces alongside
  // NavLink's onNavigate; covers edge case of programmatic navigation).
  useEffect(() => {
    setOpen(false);
  }, [pathname]);

  return (
    <Dialog.Root open={open} onOpenChange={setOpen}>
      <Dialog.Trigger
        aria-label={t('openMenu')}
        className={[
          'md:hidden',                         // hide on desktop
          'inline-flex items-center justify-center',
          'w-10 h-10 rounded',
          'text-ink hover:text-accent',
          'focus-visible:outline-none',
          'focus-visible:ring-2 focus-visible:ring-accent-ring',
        ].join(' ')}
      >
        {/* Inline hamburger SVG — avoids adding an icon library for 3 glyphs total */}
        <svg
          width="22" height="22" viewBox="0 0 24 24"
          fill="none" stroke="currentColor" strokeWidth="2"
          strokeLinecap="round" strokeLinejoin="round"
          aria-hidden="true"
        >
          <line x1="4" y1="7"  x2="20" y2="7" />
          <line x1="4" y1="12" x2="20" y2="12" />
          <line x1="4" y1="17" x2="20" y2="17" />
        </svg>
      </Dialog.Trigger>

      <Dialog.Portal>
        <Dialog.Overlay
          className="fixed inset-0 z-40 bg-ink/20"
        />
        <Dialog.Content
          aria-label={t('openMenu')}
          className={[
            'fixed inset-y-0 right-0 z-50',
            'w-72 max-w-[85vw]',
            'bg-surface',
            'shadow-md',
            'p-6 pt-4',
            'flex flex-col',
            'focus:outline-none',
          ].join(' ')}
        >
          {/* Hidden but announced title — Radix requires Dialog.Title for a11y */}
          <Dialog.Title className="sr-only">
            {t('openMenu')}
          </Dialog.Title>

          <div className="flex justify-end mb-6">
            <Dialog.Close
              aria-label={t('closeMenu')}
              className={[
                'inline-flex items-center justify-center',
                'w-10 h-10 rounded',
                'text-ink hover:text-accent',
                'focus-visible:outline-none',
                'focus-visible:ring-2 focus-visible:ring-accent-ring',
              ].join(' ')}
            >
              <svg
                width="22" height="22" viewBox="0 0 24 24"
                fill="none" stroke="currentColor" strokeWidth="2"
                strokeLinecap="round" strokeLinejoin="round"
                aria-hidden="true"
              >
                <line x1="6"  y1="6"  x2="18" y2="18" />
                <line x1="18" y1="6"  x2="6"  y2="18" />
              </svg>
            </Dialog.Close>
          </div>

          <nav aria-label={t('openMenu')} className="flex flex-col gap-1">
            {NAV_ITEMS.map((item) => (
              <NavLink
                key={item.href}
                href={item.href}
                onNavigate={() => setOpen(false)}
                className="text-base py-3 px-2 rounded"
                activeClassName="bg-surface-alt"
              >
                {tNav(item.labelKey)}
              </NavLink>
            ))}
          </nav>

          <div className="mt-auto pt-6">
            <LocaleToggle className="w-full text-left px-2 py-3 text-base" />
          </div>
        </Dialog.Content>
      </Dialog.Portal>
    </Dialog.Root>
  );
}
```

Key correctness notes:
- `Dialog.Trigger` itself is hidden on desktop via `md:hidden`. The SiteHeader plan doesn't need to wrap it in a media-query — the component carries the responsive class inside.
- `Dialog.Title` is required by Radix for screen-reader labelling; use `sr-only` so it's announced but invisible.
- `onNavigate={() => setOpen(false)}` on every NavLink handles the "tap link to close" requirement from CONTEXT.md.
- `useEffect([pathname])` handles the edge case where navigation occurs without a click (e.g., future programmatic redirects).
- Active-link visual inside the drawer uses `bg-surface-alt` via `activeClassName` — a shaded row is the academic-restraint equivalent of a "current item" indicator inside a drawer (no border).
- z-index ladder: overlay `z-40`, content `z-50` (skip link `z-[100]` stays above if user focuses it while drawer open).
- Width: `w-72 max-w-[85vw]` — fixed comfortable width on tablet, capped at 85vw on narrow phones so the drawer never fills the whole screen (standard academic-restraint drawer sizing).

Do NOT:
- Hand-roll focus trap logic — Radix handles it.
- Add a body `overflow: hidden` toggle — Radix handles scroll lock via the overlay's pointer-events.
- Add animations beyond whatever Radix provides — the 01-02 design constraint is minimal motion.

Use `next/image` for the logo since `public/logo_cosmo.png` is a raster file (already committed to repo — verified at plan time).

```tsx
'use client';

import Image from 'next/image';
import {useTranslations} from 'next-intl';
import {Link} from '@/i18n/navigation';
import {siteConfig} from '@/config/site';
import {NAV_ITEMS} from './nav-items';
import {NavLink} from './NavLink';
import {LocaleToggle} from './LocaleToggle';
import {MobileNav} from './MobileNav';

export function SiteHeader() {
  const tNav = useTranslations('nav');

  return (
    <header
      className={[
        'sticky top-0 z-30',
        'bg-surface',
        'shadow-sm',            // the one allowed separator — no border
        'h-14',                 // matches --header-height token (56px)
      ].join(' ')}
    >
      <div
        className={[
          'mx-auto max-w-5xl',
          'h-full px-6',
          'flex items-center gap-6',
        ].join(' ')}
      >
        {/* Brand mark — logo links to locale-prefixed home */}
        <Link
          href="/"
          aria-label={siteConfig.groupName}
          className={[
            'inline-flex items-center shrink-0',
            'focus-visible:outline-none',
            'focus-visible:ring-2 focus-visible:ring-accent-ring rounded',
          ].join(' ')}
        >
          <Image
            src="/logo_cosmo.png"
            alt={siteConfig.groupName}
            width={40}
            height={40}
            priority
            className="h-8 w-auto"
          />
        </Link>

        {/* Desktop nav — hidden below md */}
        <nav
          aria-label="Primary"
          className="hidden md:flex items-center gap-5 ml-2"
        >
          {NAV_ITEMS.map((item) => (
            <NavLink key={item.href} href={item.href} className="text-sm">
              {tNav(item.labelKey)}
            </NavLink>
          ))}
        </nav>

        {/* Desktop-only locale toggle pushed to the far right */}
        <div className="hidden md:flex ml-auto items-center">
          <LocaleToggle />
        </div>

        {/* Mobile nav — MobileNav is internally md:hidden on its trigger */}
        <div className="md:hidden ml-auto">
          <MobileNav />
        </div>
      </div>
    </header>
  );
}
```

Layout reasoning:
- `sticky top-0 z-30` + `bg-surface` + `shadow-sm` is RESEARCH.md Pattern 6 — visual separation without a border, within the shadow ceiling.
- `h-14` = 56px, exactly matching the `--header-height` token Plan 01 added so the skip-link's `scroll-margin-top` aligns.
- `max-w-5xl` is a reasonable academic-restraint container width. Page content can use narrower widths; the header spans the allowed max.
- Desktop breakpoint: Tailwind's `md` (768px). Below 768, inline nav hides and MobileNav's trigger appears. This breakpoint covers phones (small/narrow) and small tablets.
- Logo sizing: `h-8 w-auto` keeps the logo at 32px tall inside the 56px header (sensible visual weight). `width={40} height={40}` match the PNG's intrinsic ~1:1 aspect at the largest expected size — `next/image` handles the downscale. `priority` because the logo is in the initial viewport on every route (LCP candidate).
- `alt={siteConfig.groupName}` — the logo's accessible name is the group name, so screen readers announce "Grupo de Cosmología, link" when focused (Spanish on /es, English on /en — wait: `siteConfig.groupName` is canonical Spanish per 02-01 decision. That's intentional: the institution's name is Spanish everywhere. Screen-reader users on /en will still hear "Grupo de Cosmología" which is the correct institutional identity).
- Active-state rendering happens inside each NavLink (Plan 03), so SiteHeader does not need `usePathname` itself.

Do NOT:
- Add a wordmark text next to the logo (CONTEXT.md: "No text wordmark unless planning discovers the logo alone reads too weak"). The 32px PNG is legible; defer to human-verify checkpoint in Plan 05 if it reads weak.
- Add a search input, breadcrumb strip, dark-mode toggle, or any other chrome (CONTEXT.md deferred-ideas section).
- Add a media-query wrapper around the logo itself — the logo is always visible on both breakpoints.
