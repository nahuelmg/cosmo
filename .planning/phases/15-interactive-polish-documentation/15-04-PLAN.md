Two edits in PersonCard.tsx:

  1. **Image zoom (MICRO-03):** in the `<Image>` element (currently lines 18-25 per RESEARCH.md), change the className from:
     ```tsx
     className="object-cover"
     ```
     to:
     ```tsx
     className="object-cover motion-safe:transition-transform motion-safe:duration-200 motion-safe:group-hover:scale-[1.02]"
     ```

     Why each token:
     - `motion-safe:` prefix on EVERY transform utility: CONTEXT.md "Reduced motion handling: Tailwind motion-safe: prefix on every transition site. When the user prefers reduced motion, transitions are simply absent."
     - `duration-200`: MICRO-03 spec says 200ms ease-out for the scale transform — CONTEXT.md "MICRO-03's 200ms is a documented per-spec exception (the requirement itself names 200ms)". DO NOT change to duration-150.
     - `group-hover:scale-[1.02]`: the parent `<Link>` already has `group` class (PersonCard.tsx:15 verified in RESEARCH.md), so `group-hover:` works on the child `<Image>`. Arbitrary value `scale-[1.02]` is required (Tailwind's `scale-105` = 1.05, too aggressive per CONTEXT.md "1.02 is the sweet spot, not 1.05").
     - The wrapper `<div className="relative w-full aspect-[4/5] bg-surface">` (line 17) is inside the outer `<Link>` which has `overflow-hidden` (line 15) — verified in RESEARCH.md, the scale won't bleed out of the card.

  2. **Ring offset (BTN-02 sweep):** in the outer `<Link>` className (line 15), change `'focus-visible:ring-2 focus-visible:ring-accent-ring'` to `'focus-visible:ring-2 focus-visible:ring-accent-ring focus-visible:ring-offset-2 focus-visible:ring-offset-surface'`.
     - The PersonCard sits on the page light-cream surface (`bg-surface-alt` is the card itself; the offset reads against the page background). `ring-offset-surface` is correct per CONTEXT.md "ring-offset-surface on light backgrounds".

  3. **Initials placeholder branch:** DO NOT add zoom to the placeholder `<div>` (lines 27-37 per RESEARCH.md). RESEARCH.md component-specific finding: "scaling letters reads as a glitch. Apply MICRO-03 only to the `<Image>` branch." Document this exemption in the SUMMARY.

NO other changes — the pre-existing `transition-transform duration-150 hover:-translate-y-0.5` on the outer `<Link>` (the card lift) is unchanged; that's a separate transition on a different element, both render together on hover.
