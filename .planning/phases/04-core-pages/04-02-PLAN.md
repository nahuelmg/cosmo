  <action>
    Rewrite `src/app/[locale]/page.tsx` entirely, deleting the Phase 1 Greek-probe placeholder. The new page is an async Server Component that composes HeroCarousel (client leaf from 04-01), Highlights (server, task 1), and PartnerStrip (server, task 1).

    Exact structure:

    ```tsx
    import Image from 'next/image';
    import { setRequestLocale, getTranslations } from 'next-intl/server';
    import { routing } from '@/i18n/routing';
    import { localize, siteConfig } from '@/content';
    import { HeroCarousel } from '@/components/home/HeroCarousel';
    import { Highlights } from '@/components/home/Highlights';
    import { PartnerStrip } from '@/components/home/PartnerStrip';

    type Locale = (typeof routing.locales)[number];
    type Props = { params: Promise<{ locale: Locale }> };

    export default async function HomePage({ params }: Props) {
      const { locale } = await params;
      setRequestLocale(locale);

      const t = await getTranslations('home');

      const slides = [
        { src: '/Portadas/portada_1.jpg', alt: '', width: 1920, height: 820 },
        { src: '/Portadas/portada_2.png', alt: '', width: 1920, height: 820 },
        { src: '/Portadas/portada_3.jpg', alt: '', width: 1920, height: 820 },
      ];

      const tagline = localize(siteConfig.tagline, locale);
      const affiliation = siteConfig.affiliations
        .map(a => localize(a.name, locale))
        .join(' · ');

      const partners = siteConfig.affiliations.map(a => ({
        name: localize(a.name, locale),
        url: a.url,
      }));

      return (
        <>
          <HeroCarousel
            slides={slides}
            groupName={siteConfig.groupName}
            tagline={tagline}
            affiliation={affiliation}
          />

          <section className="mx-auto max-w-3xl px-6 py-16">
            <p className="font-serif text-lg leading-relaxed text-ink-muted whitespace-pre-line">
              {t('intro')}
            </p>
          </section>

          <Highlights
            sectionTitle={t('highlightsTitle')}
            cards={[
              { title: t('highlight1Title'), body: t('highlight1Body') },
              { title: t('highlight2Title'), body: t('highlight2Body') },
              { title: t('highlight3Title'), body: t('highlight3Body') },
            ]}
          />

          <PartnerStrip
            title={t('partnersTitle')}
            partners={partners}
          />
        </>
      );
    }
    ```

    Guardrails:
    - Delete the Phase 1 Greek-probe block entirely — decision 01-04 scheduled removal for Phase 3; Phase 3 deferred, Phase 4 clears it.
    - The page MUST return a Fragment (no wrapping `<main>`) — decision 03-05 locks the single `<main>` in the layout.
    - `alt=""` on slides is correct per RESEARCH.md — the overlay carries the semantic text; images are decorative.
    - Use `next/image` only — no raw `<img>` tags (PERF-02 / A11Y-05 downstream).
    - Use `getTranslations` (server) — never `useTranslations` here; the page is async.
    - `localize(siteConfig.tagline, locale)` returns a plain string; pass as prop.
    - `whitespace-pre-line` on the intro paragraph lets the message value use `\n\n` to break into paragraphs visually without requiring a split at the page level.
    - Do NOT add hreflang / canonical / OG metadata here — Phase 5 owns SEO.
    - Do NOT import `useTranslations` — this is a server component.
    - Do NOT call `getPublications()` or any content accessor for highlight cards — the CONTEXT/RESEARCH decision is that highlights are static messages-file copy (open question #3 recommendation).
  </action>
