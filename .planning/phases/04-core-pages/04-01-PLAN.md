      ```ts
      interface Slide { src: string; alt: string; width: number; height: number; }
      interface HeroCarouselProps {
        slides: Slide[];
        groupName: string;
        tagline: string;
        affiliation: string;
      }
      ```
    - Internal state: `const [index, setIndex] = useState(0); const [isPaused, setIsPaused] = useState(false);`
    - Constants: `const VISIBLE_MS = 7000; const TRANSITION_MS = 1000;` (CONTEXT decision: 7s visible + 1s crossfade).
    - Timing effect: on every `index` change, `setTimeout(advance, VISIBLE_MS)` wrapping `setIndex(i => (i + 1) % slides.length)`. Cleanup clears the timer. Skip the timer when `isPaused === true` OR `window.matchMedia('(prefers-reduced-motion: reduce)').matches`.
    - Visibility effect: `addEventListener('visibilitychange', ...)` — on `document.hidden`, clear the timer via a ref. On return-to-visible, the index/isPaused effect re-runs and restarts timing.
    - Hover pause is DELIBERATELY NOT implemented — CONTEXT decision: hover/focus do NOT pause; only explicit button.
    - DOM structure:
      * Outer `<div aria-roledescription="carousel" className="relative w-full aspect-[21/9] overflow-hidden rounded-md">`.
      * For each slide: `<div key={slide.src} aria-hidden={i !== index} className={absolute inset-0 transition-opacity duration-[1000ms] + (i === index ? 'opacity-100' : 'opacity-0')}>` containing `<Image src={slide.src} alt={slide.alt} fill priority={i === 0} sizes="100vw" className="object-cover" />`.
      * Static overlay (same every slide per CONTEXT decision): `<div className="absolute inset-0 bg-gradient-to-t from-ink/60 to-ink/10 flex flex-col justify-end p-8 md:p-12">` with three text lines — groupName (h1, font-serif, text-4xl md:text-5xl, text-surface), tagline (p, text-surface/90), affiliation (p, text-surface/70, text-sm). WCAG-AA overlay contrast uses `bg-gradient-to-t from-ink/60 to-ink/10` which guarantees sufficient contrast behind text while keeping the top of the image unobscured. If lint flags the dynamic duration class, use a static Tailwind class `duration-1000` instead of `duration-[1000ms]`.
      * Controls cluster: `<div role="group" aria-label={t('controls')} className="absolute bottom-4 right-4 flex items-center gap-2">`.
        - Dot buttons: `<button type="button" aria-label={t('goToSlide', {n: i + 1})} aria-pressed={i === index} onClick={() => setIndex(i)} className="w-2.5 h-2.5 rounded-full focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-surface/70 active:scale-95 transition-[background-color,transform] duration-75 ..." />` with background `bg-surface` when active, `bg-surface/50` otherwise.
        - Pause/play button: `<button type="button" aria-label={isPaused ? t('play') : t('pause')} aria-pressed={isPaused} onClick={() => setIsPaused(p => !p)} className="ml-1 p-1 text-surface/80 hover:text-surface focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-surface/70 rounded">` with two tiny inline SVG glyphs (2 rects for pause, 1 triangle for play) — no lucide dependency needed for 2 glyphs, matches 03-04 decision on inline SVGs.
    - Translations: `import { useTranslations } from 'next-intl'; const t = useTranslations('carousel');`. Keys used: `controls`, `goToSlide` (with `n` param), `pause`, `play`.
    - Hydration safety: `useState(0)` is deterministic; the reduced-motion check lives inside the effect so the server renders slide 0 with paused=false and the client re-evaluates on mount — no SSR branching outside effects.
