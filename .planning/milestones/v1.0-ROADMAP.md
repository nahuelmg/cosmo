# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-04-18
**Phases:** 1-6
**Total Plans:** 31

## Overview

Six phases take the project from an empty repo to a deployed bilingual institutional website. Phase 1 locks the foundations that ripple through every URL and component (bootstrap, design system, i18n routing). Phase 2 stabilises the typed content layer so pages can consume placeholder JSON safely. Phase 3 builds the layout shell and language toggle every page depends on. Phase 4 ships the seven pages in parallel. Phase 5 makes the site discoverable. Phase 6 verifies accessibility and performance before launch.

## Milestone Summary

**Scope adjustments:**
- PUBS-03 (Publications filter UI) — deferred beyond v1.0 (2026-04-18, Phase 4 planning)
- PUBS-04 (URL-synced filter state) — deferred beyond v1.0 (depends on PUBS-03)
- HOME-03 — pause button wording replaced with dot-only control; hover/focus deliberately don't pause (2026-04-18, Phase 4 human-verify)

**Key Decisions made during milestone:**
- Vercel-only deployment (dual-build overhead not worth cost)
- JSON/YAML content over CMS
- CSS-first Tailwind v4 (`@theme` in `globals.css`)
- No-border policy (hierarchy via typography + whitespace)
- Single `<main>` landmark in `[locale]/layout.tsx`
- `EmailLink` two-file obfuscation (zero `mailto:` in prerendered HTML)
- `buildPageMetadata` helper as single SEO-composition site
- Static `metadata` export at locale layout (preserves SSG)
- `getPathname` as URL source of truth (pathnames map drives sitemap + nav + canonicals)

**Issues Resolved:**
- Build-time JSON content validation with Zod prebuild + JSON Schema IntelliSense (no CMS needed)
- Locale-toggle preserves path + query across all routes (NAV-02, I18N-04)
- axe-core 0 critical violations across 8 Spanish pages (A11Y-01)
- 45 fully-static routes with 0 SSR fallback (PERF-01)
- Cross-phase integration verified: 0 dead imports on hot paths, 0 `mailto:` in prerendered HTML, sitemap slug set == `generateStaticParams` slug set

**Issues Deferred:**
- PERF-02 (CLS on 7 of 8 pages), PERF-04 (mobile 4G LCP Home/People/Publications), PERF-05 (Contact LCP element) — localhost `pnpm start` is a pessimistic LCP proxy; re-measure on Vercel production
- NAV-04 mobile drawer live-deploy 375px verification (structural done)
- HeroCarousel pause / reduced-motion / MapEmbed IntersectionObserver runtime verification (deferred from 04-02 human-verify)

**Technical Debt Incurred:**
- `MobileNav.tsx:87` `focus:outline-none` — box-shadow ring provides visible focus; lint flag remains
- `SiteFooter.tsx:1` unused `next/link` dead import — flip to `@/i18n/navigation` on next edit to that file
