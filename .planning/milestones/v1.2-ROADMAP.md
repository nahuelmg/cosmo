## Milestone Summary

**Key Decisions (carried forward into PROJECT.md):**

- **Type scale versioning pattern** — supersession notes inline in MASTER.md Type Scale table, not a separate changelog page. Establishes the doc pattern for v1.3+ token changes.
- **SPACE-03 two-tier card padding rule** — dense `p-4` (grid cards: PersonCard) / spacious `p-6` (feature cards: ResearchCard, OutreachCard). Flat across breakpoints — no CSS abstractions, no responsive variants. `SessionRow py-5` documented as dense-row equivalent (list items with dividers).
- **`--text-5xl: 2.5rem` caps hero H1 at 40 px (not Tailwind default 48 px)** — HeroCarousel only; inner page H1s use `text-3xl md:text-4xl` (36 px). `tracking-tight` removed from all inner-page H1s (`@layer base` `-0.01em` governs).
- **PersonCard `max-w-[240px] w-full mx-auto` self-capping pattern** — card caps itself, centers via `mx-auto` inside potentially wider grid cell. Combined with `xl:grid-cols-4` inside `max-w-6xl` wrapper gives ~258 px cell / 240 px card at xl.
- **Aspect-ratio via wrapper (`aspect-[4/5]`) rather than fixed w/h on `<Image>` for LCP photos** — preserves Phase 6 `fill` + parent-aspect pattern so the `link rel=preload imagesrcset` hint stays stable.
- **Flat `sizes` hint `"(min-width: 640px) 240px, 100vw"`** — card caps at 240 px from `sm` upward, so a flat hint is accurate everywhere and avoids per-breakpoint lies.
- **PersonDetail mobile layout stacked + centered** — inline at 375 px leaves ~147 px for bio which breaks line length; stacked preserves reading flow. `sizes="(min-width: 768px) 180px, 180px"` (narrow-constant, not `…, 100vw`) tightens srcset preload pool.
- **HeroCarousel dots use `p-[17px]` arbitrary value** (17+10+17=44 px exactly) over Tailwind `p-3`+spacer — `p-3` gives only 34 px; only 2 uses of 17 px → below tokenize threshold. `gap-0` edge-to-edge.
- **Tailwind class source-order cascade** used in NavLink so mobile keeps `py-3` despite base growing to `py-1.5` — `base + className` concatenation leaves later class winning; no `twMerge` needed.
- **Hoisted `base` const in SourceFilter** — prevents active/inactive branch drift when future contributors edit one; snapshot test updated to match.
- **Inline-text links exempted from BTN-01's 44×44 rule** (PartnerStrip, OutreachCard learn-more, SiteFooter EmailLink, ContactDetails social, SessionRow paper-link, PublicationEntry arXiv/DOI/source-pill) per WCAG 2.5.5 AAA inline-text exception; documented in OVERRIDES.md + MASTER.md Universal Rules.
- **SkipLink (`focus:` not `focus-visible:`) deliberately not rewritten** in the focus-ring sweep — Phase 3 pattern, sr-only chip is keyboard-only by definition; CI drift gate excludes it via `focus-visible:` anchor.
- **MICRO-03 `motion-safe:` prefix on every transform utility** on PersonCard image — respects `prefers-reduced-motion`. Card-lift `hover:` on outer Link is a pre-existing carryover, flagged as observation.
- **CI drift gate** (`.github/workflows/lint-rings.yml`) — PCRE negative lookahead on `focus-visible:ring-` in `src/`, allows `ring-2` / `ring-accent-ring` / `ring-offset-*`, fails on anything else. Enforces BTN-02 uniformity going forward.
- **MASTER.md Component Specs rewritten as Tailwind recipes** (not raw CSS class abstractions like `.btn-primary`) — codebase has zero CSS class analogues; raw CSS blocks were load-bearing on nothing.
- **OVERRIDES.md append pattern** — v1.2 deltas added as new `## v1.2 Overrides` table section; v1.0 numbered list preserved verbatim.
- **Desktop NavLink deliberately has no `focus-visible:ring-*`** — inherits browser UA focus ring. Documented in MASTER.md recipe and 15-VERIFICATION. Flagged as observation for future polish if judged insufficient on live site.
