# Milestone v1.1: arXiv + InspireHEP Publication Sync

**Status:** ✅ SHIPPED 2026-04-19
**Phases:** 7–12
**Total Plans:** 13 (2 + 1 + 3 + 1 + 3 + 3)

## Overview

Auto-populate the group's `/publications` archive (and each current member's profile) from InspireHEP (BAI) + arXiv (ORCID-linked) on a weekly GitHub Actions cron, replacing v1.0's hand-curated `content/publications.json` while preserving the fully-static SSG guarantee (PERF-01).

**Locked decisions:**
- Build-time GitHub Action (weekly Monday 06:00 UTC) — no runtime ISR
- Sources: InspireHEP (BAI) + arXiv (ORCID-linked author feed) — entries source-tagged, no cross-source DOI dedup
- Author linkage: explicit `inspirehep_id` + `orcid_id` in `content/people.json` (arxiv_id reconceived to orcid_id after real-data check found arXiv author slugs unavailable)
- Failure mode: last-good JSON preserved on any upstream failure; `jq`-level payload diff-guard prevents spurious commits on `_meta.synced_at` drift
- Profile display: last-10-years window on `/people/[slug]`; full archive on `/publications`
- Scope: current PIs/postdocs/PhDs only — past members keep v1.0's flat list

## Milestone Summary

**Key Decisions:**
- `arxiv_id` reconceived to `orcid_id` in Phase 7-02 after real-data check revealed arXiv author slugs are not reliably discoverable; ORCID-indexed arXiv Atom feed replaces it cleanly
- BAI regex loosened to `/^[A-Z][A-Za-z-]*(\.[A-Za-z-]+)+\.\d+$/` to accept multi-segment names (e.g., `Tomas.F.Chase.1`)
- Cross-source dedup scoped as intra-source only per Phase 9 decision — source-tagged separate entries remain v1.1's design choice; cross-source DOI dedup deferred to v1.2+
- CI workflow pushes direct-to-main (not PR) per Phase 10 decision — group publishing cadence is slow; auto-commit with Zod validation + Vercel build guard deemed safe enough
- `_meta` shape improved over spec (`synced_at` + `sources[]` + `counts` + `warnings[]` vs spec's `{synced_at, status}`) — intentional, no-op for downstream consumers
- Payload-aware diff-guard (`jq -cS '.publications'` vs `HEAD`) used instead of plain `git diff --quiet` to ignore `_meta.synced_at` byte drift — prevented spurious commits and Vercel rebuilds
- Member-author bold highlighting DROPPED per user feedback in Phase 12 polish (PUBS-12 softened, aligned with PEOP-14 pattern)
- Count subtitle on `/people/[slug]` DROPPED per 11-CONTEXT decision (PEOP-14 softened — list length self-communicates)
- Phase 12 explicitly scoped as gap-closure phase driven by milestone audit output
