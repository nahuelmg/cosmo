## v1 Requirements for This Milestone

### Typography (TYPO)

- [x] **TYPO-01:** Added `--text-5xl` (40 px / 2.5 rem) token in `globals.css` `@theme`; documents the hero size and stops `text-5xl` from falling through to Tailwind default 48 px. **Shipped Phase 13-01.**
- [x] **TYPO-02:** Softened `--text-4xl` from 32 px to 36 px so H1 ≥ 1.20 × H2 (30 → 36 = 1.20×) and the heading hierarchy on People / Research / Contact reads clearly. **Shipped Phase 13-01.**
- [x] **TYPO-03:** Re-keyed every existing H1 usage against the new scale with consistent weight (`font-semibold`, 600) and letter-spacing (`-0.01em` from `@layer base`); `tracking-tight` removed from 7 inner-page H1s. **Shipped Phase 13-02.**
- [x] **TYPO-04:** Audited body-text usage across components; nav consolidated from `text-base lg:text-lg` to uniform `text-sm`. **Shipped Phase 13-02.** (Note: post-milestone commit `1cf9cf8` later reverted NavLink to `text-lg` — tracked as doc drift in v1.3.)
- [x] **TYPO-05:** Documented final scale + weights + line-heights in `design-system/cosmology-group-uba/MASTER.md` "Type Scale" table; v1.0 scale marked as superseded inline. **Shipped Phase 13-04.**

### Buttons & Interactive Elements (BTN)

- [x] **BTN-01:** Every interactive element has effective tap target ≥ 44 × 44 px (WCAG 2.5.5 AAA / iOS HIG). Visible chrome may be smaller with padding compensating. **Shipped Phase 15-01..05.** Inline-text links exempted per WCAG 2.5.5 AAA and documented in OVERRIDES.md.
- [x] **BTN-02:** Unified every `focus-visible:ring-*` ring colour on `ring-accent-ring`; removed `ring-surface/70` variant from HeroCarousel; contrast-safe dark-on-image alternative (`ring-offset-black/40`) used where needed. **Shipped Phase 15-01.** CI drift gate enforces going forward.
- [x] **BTN-03:** Standardised carousel controls — dots wrapper grows to 44×44 tap area (`p-[17px]` around 10 px dot); pause/play bumped to `w-11 h-11` with 14×14 centred glyph. **Shipped Phase 15-01.**
- [x] **BTN-04:** Standardised `SourceFilter` pills: `px-3.5 py-1.5` (≥ 36 px visual height) + unified focus ring. **Shipped Phase 15-03.**
- [x] **BTN-05:** Added consistent vertical padding to `NavLink` (`py-1.5`) and matched `LocaleToggle` padding so they read as a single interactive row at 44 px inside the `h-24` flex-centered header. **Shipped Phase 15-02.**
- [x] **BTN-06:** Documented button/pill/link sizing recipes in `design-system/cosmology-group-uba/MASTER.md` "Component Specs" section as inline Tailwind utility recipes (not raw CSS abstractions). **Shipped Phase 15-06.**

### Spacing & Layout Density (SPACE)

- [x] **SPACE-01:** Codified page-container widths: `max-w-5xl` for prose (Contact, PersonDetail, Journal Club, Publications, PeoplePlainSection); `max-w-6xl` for grids (People header, PeopleSection, Outreach, Research, Highlights, PartnerStrip). Zero `max-w-4xl` in codebase. **Shipped Phase 13-02.**
- [x] **SPACE-02:** Codified vertical-rhythm scale: section `py-12`, page wrapper `py-16`. Hero `py-20` reserved convention (HeroCarousel uses internal layout). **Shipped Phase 13-02.**
- [x] **SPACE-03:** Two-tier card padding rule — dense `p-4` (PersonCard), spacious `p-6` (ResearchCard, OutreachCard); SessionRow `py-5` as dense-row equivalent; zero `p-8` in card contexts (ResearchCard was the only outlier, reduced). **Shipped Phase 13-03.**
- [x] **SPACE-04:** Documented container widths + vertical rhythm + card padding tiers in `design-system/cosmology-group-uba/MASTER.md` "Layout" subsection with SPACE-01/02/03 cross-references. **Shipped Phase 13-04.**

### Media Sizing (MEDIA)

- [x] **MEDIA-01:** `PersonCard` sized down ~35%. Solution: `max-w-[240px] w-full mx-auto` self-cap + PeopleSection `xl:grid-cols-4`. Photo aspect shifted to `aspect-[4/5]` portrait. **Shipped Phase 14-01.**
- [x] **MEDIA-02:** `PersonDetail` hero photo reduced from 240 px to 180 px; `aspect-[4/5]` portrait; mobile cap via `max-w-[180px] mx-auto md:mx-0`; grid template `md:grid-cols-[180px_1fr]`. **Shipped Phase 14-02.**
- [x] **MEDIA-03:** HeroCarousel aspect ratio + min-height re-checked against new scale. 5-viewport × 6-check audit all PASS (H1 wrap, scrim truncation, face crop, control reachability, min-height, LCP preload). No code change needed. **Closed Phase 14-03.**
- [x] **MEDIA-04:** Outreach + home-page highlight imagery reviewed. Homepage has exactly one next/image surface (HeroCarousel, audited under MEDIA-03). OutreachCard image wrapper is dormant in current content (0 of 4 activities has image field). Filed FU-OUTR-01 for re-audit on first image. **Closed Phase 14-03.**
- [x] **MEDIA-05:** `next/image` `sizes` attributes updated — PersonCard `"(min-width: 640px) 240px, 100vw"`, PersonDetail hero `"(min-width: 768px) 180px, 180px"` (narrow-constant to tighten preload srcset under mobile cap). **Shipped Phases 14-01 + 14-02.**
