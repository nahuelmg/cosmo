## Deviations

### Deviation #1: JSON-LD `identifier.value` format (cosmetic)

- **Location:** [src/lib/schemas.ts:132](src/lib/schemas.ts#L132)
- **Expected per milestone spec:** `identifier.value = "https://doi.org/10.1016/j.nima.2020.164490"`
- **Actual:** `identifier.value = "10.1016/j.nima.2020.164490"` (bare DOI); URL form exists in `sameAs[]`
- **Impact:** None — Schema.org `PropertyValue` accepts either representation with `propertyID: "DOI"`; Google rich-results handle both
- **Recommendation:** Leave as-is unless SEO team flags. If later required, one-line patch: `value: \`https://doi.org/${pub.doi}\``
